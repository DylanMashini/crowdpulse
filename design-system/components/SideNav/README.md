# SideNav

The dashboard's fixed left navigation. Provide `items` (`id`, `label`, `icon`, optional `count`), the `active` id, `onSelect(id)` and an optional `footer` node.

- Five destinations: Check-in, Waiting room, Tickets, Flag settings, Pilot results.
- `count` on Waiting room is the number of flagged plus overdue tickets, as a plain number.
- Desktop only, `nav-width` wide. The mobile roles have no navigation rail.
