# Icon

The system's own 24px line icons, drawn at 1.5 stroke in the current text colour. Provide `name`, optional `size` (16 in the dashboard, 20 on the phone, 24 where it stands alone) and a `label` only when the icon stands alone without text.

- Names: clock, flag, check, bell, camera, lock, no-reading, pulse, breath, list, sliders, chart, ticket, draft, trash, scan, user, video, thermal, chevron, eye-off.
- An icon always sits beside a word in status and provenance marks. It never replaces the word.
- No emoji, no filled icons, no second icon set.
