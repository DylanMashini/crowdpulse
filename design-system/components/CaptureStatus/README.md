# CaptureStatus

What the operator needs to trust a sitting: frame rate, dropped frames, exposure and phone temperature, with the privacy line. Provide `fps`, `dropped`, `exposureLocked`, `thermal` and optionally `note`.

- A value outside its expected range turns `watch` and gains the flag icon.
- The privacy note is part of the component and stays visible during capture.
- Operator-facing only. The patient sees the Viewfinder and SittingTimer.
