# TicketNumber

The anonymous ticket number that stands in for a patient everywhere. Provide `number` and `size` (`sm` in tables, `md` in tiles and cards, `lg` in headers, `xl` on the patient-facing screen).

- The ticket number is the only identifier on any screen. No names, initials, ages or visit reasons, including in tooltips and notifications.
- Always preceded by the word Ticket.
